# Itlhokomeleng Association for the Aged & Disabled

## Project Overview - This is Part 2

This website was developed for the Itlhokomeleng Association for the Aged & Disabled as part of the WEDE5020 Web Development project.

The purpose of the website is to provide information about the organisation, its services, and ways in which members of the community can get involved and support its work.

## Website Pages

The website includes the following pages:

* **Home** – Introduction to the organisation and its purpose.
* **About Us** – Information about Itlhokomeleng Association.
* **Services** – Information about the services provided by the organisation.
* **Get Involved / Enquiry** – Information for people interested in supporting or engaging with the organisation.
* **Contact Us** – Contact information and an enquiry form.

The website includes:
