# Itlhokomeleng Association for Aged & Disabled Website

1. Project Overview

This project involves the design and development of a responsive website for the Itlhokomeleng Association for Aged & Disabled, a community-based non-profit organisation located in Alexandra, Johannesburg, South Africa.

The purpose of the website is to establish an online presence for the organisation, provide information about its history and services, promote community involvement, and make it easier for visitors to contact the organisation.

The website was developed as part of the WEDE5020 Web Development module.

2. Live Website

Website: https://pertunia1991.github.io/Itlhokomeleng-Website/

GitHub Repository: https://github.com/Pertunia1991/Itlhokomeleng-Website

3. Website Objectives

The main objectives of the website are to:

- Introduce visitors to the Itlhokomeleng Association.
- Provide information about the organisation's history, mission and vision.
- Explain the services offered to older persons and persons with disabilities.
- Encourage volunteering, sponsorships and community support.
- Provide contact information and enquiry facilities.
- Improve the organisation's online visibility through search engine optimisation (SEO).

4. Website Pages

The website consists of five main pages:

Page and Description 

| Home - Introduces the organisation and highlights its work, services and activities. 
| About Us - Provides the organisation's background, history, mission, vision and leadership information. 
| Services - Presents the care and support services offered by the organisation. 
| Get Involved - Allows visitors to make volunteering, sponsorship and support enquiries. 
| Contact - Provides contact information, location details and a contact form. 

5. Technologies Used

The following technologies were used in developing the website:

- HTML5:Used to structure the website content and pages.
- CSS3: Used for styling, layout, visual presentation and responsive design.
- JavaScript:Used to implement interactive functionality and client-side form validation.
- GitHub: Used for source code management and version control.
- GitHub Pages: Used to host and publish the website.

6. Website Features and Functionality

The website includes the following features:

- Responsive navigation across all website pages.
- Mobile-friendly layouts for different screen sizes.
- Interactive service search functionality.
- Image gallery with a lightbox feature.
- Embedded Facebook video showcasing the organisation.
- Contact and enquiry forms with client-side validation.
- Interactive feedback messages for form validation.
- Consistent branding, colours and navigation throughout the website.
- Internal links connecting the different website pages.

Note:The contact and enquiry forms currently provide client-side validation and confirmation messages. They are not connected to a backend service and therefore do not transmit or store submitted information.

7. Search Engine Optimisation (SEO)

Search engine optimisation techniques were implemented to improve the website's visibility and accessibility.

### On-page SEO

The following techniques were applied:

- Unique page titles for individual website pages.
- Meta descriptions for search engine listings.
- Relevant keywords incorporated into website content.
- Structured headings using appropriate HTML heading elements.
- Descriptive alternative text for images.
- Internal linking between website pages.
- Descriptive image filenames.
- Responsive layouts for mobile devices.

### Technical SEO

The following technical SEO files were created:

- `robots.txt` – Provides instructions to search engine crawlers.
- `sitemap.xml` – Provides search engines with the website's page structure and URLs.

### Off-page SEO

Potential off-page SEO strategies include:

- Creating links to the website from relevant community organisations.
- Sharing website content through social media platforms.
- Encouraging community partners to reference the organisation's website.
- Maintaining consistent organisational contact information across online platforms.

## 9. Responsive Design and Accessibility

The website was designed to accommodate desktop, tablet and mobile users.

CSS media queries were used to adjust the layout for different screen sizes. Descriptive image alternative text was also included to improve accessibility for users relying on assistive technologies.
